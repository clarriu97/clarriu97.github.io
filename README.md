# Local development

⚠️ **This project uses pnpm as its package manager**

- Install pnpm (if you don't have it):

  ```bash
  npm install -g pnpm
  ```

- Install dependencies:

  ```bash
  pnpm install
  ```

- Start the dev server:

  ```bash
  pnpm start
  ```

- Build the app:

  ```bash
  pnpm build
  ```
